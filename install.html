Setup guide

Install in 5 minutes

Five minutes, one time. Follow the steps below — file install, your Computer ID, and your key — start to finish.

Download PineappleFX 2.0.0

Manual .zxp for extension managers, or the automated Windows installer (sets up PlayerDebugMode + pre-activates your key).

⬇ PineappleFX.zxp ⬇ Windows installer (.exe)
Enable debug mode

Run once as admin: reg add HKCU\Software\Adobe\CSXS.11 /v PlayerDebugMode /t REG_SZ /d 1 /f

Install the .zxp

Open it with an extension manager, or copy the folder to %APPDATA%\Adobe\CEP\extensions\. Use the personal .zxp from your purchase email (it comes pre-activated for your machine)

Copy your Machine ID

Restart After Effects, open Window - Extensions - PineappleFX. Click the Machine ID to copy it.

Activate

Paste the key from your email into the panel. Done - works offline from here on.

macOS paths. Copy the extension folder to ~/Library/Application Support/Adobe/CEP/extensions/, then restart After Effects. Debug mode is a Windows registry step — macOS needs only the extension manager install.
Panel doesn't show up? Confirm PlayerDebugMode reads 1 (reg query HKCU\Software\Adobe\CSXS.11 /v PlayerDebugMode), that you restarted After Effects after installing, and that your version is 22.0 or newer.
Lost your key? Log in and open My Licenses — every key is saved to your account.
