FAQ & troubleshooting

Quick answers on versions, install, licensing, extra machines, and coupons. Still stuck? Contact us.

Which After Effects versions work?

After Effects 22.0 and newer (2022 → 2026), Windows and macOS.

How do I install it?

Open the .zxp with an extension manager (e.g. Anastasiy Extension Manager) with PlayerDebugMode enabled, or copy the folder into the CEP extensions folder and restart After Effects. Full walkthrough on the Install page.

How does the license work?

Each key is locked to one machine (your panel shows its Machine ID). Paste the key once - it works offline forever. Sharing a key does nothing on other machines.

What if I change computers or lose my key?

Log in and open My Licenses — every key you've generated is saved to your Pineapple Store account. Got a second computer? The one-time $7.90 extra-machine deal in your dashboard covers it.

One key, how many machines?

Strictly one machine per key. Need a second PC? Grab the one-time $7.90 extra-machine slot in My Licenses — one extra slot per account.

Do I need internet?

Only to download. License checks work fully offline.

My key was rejected as invalid. What now?

Check three things: the key belongs to this machine's ID (each key locks to one PC), there are no missing characters when pasting, and Caps Lock didn't alter anything — pasting is safest. Your correct keys are always in My Licenses.

My coupon code doesn't work. Why?

Codes are exact-match and some have redemption caps — a fully redeemed code shows "fully redeemed". Apply the code in the Store first, then generate your key.

How do I pay for the extra-machine slot?

Open My Licenses, enter your second PC's 8-character Machine ID in the deal card, and check out with the $7.90 PayPal button. Your second key appears instantly.
